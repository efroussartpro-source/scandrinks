# Maquettes de la refonte (21/10/2026)

Copie des maquettes validées par le porteur du projet le 21/10/2026, page « Style A — tous les écrans » du canevas https://claude.ai/artifact/K9LaQSBEFJ44is1kVoCb8a. Elles servent de référence au plan `docs/superpowers/plans/2026-10-21-refonte-visuelle-et-images.md`.

Chaque fichier est un écran d'iPhone de 390 × 844 px, en HTML avec des styles en ligne : les tailles, les marges, les rayons et les couleurs se lisent dans le code. Ouvert dans un navigateur sans le canevas, l'écran s'affiche quand même, en haut à gauche.

Les données sont fictives (Sam, Léa, produits d'exemple). Les images des produits sont des illustrations dessinées à la place des vraies photos. Quand un texte d'une maquette diffère de l'app ou du plan, le plan l'emporte : les maquettes fixent l'allure, pas les textes.
